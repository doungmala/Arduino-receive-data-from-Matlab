# Arduino-receive-data-from-Matlab

Arduino Receive Data from MATLAB

A simple guide and example code for establishing serial communication to send data from MATLAB and receive it on an Arduino board.

Prerequisites

Hardware
Arduino board (Uno, Nano, Mega, etc.)
USB Cable
Software
Arduino IDE
MATLAB
MATLAB Support Package for Arduino Hardware (or using built-in serialport)
Wiring

Connect your Arduino to your computer via USB. Note the COM port assigned to your Arduino (e.g., COM3 on Windows or /dev/ttyUSB0 on Linux/Mac).
